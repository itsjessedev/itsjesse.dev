# Email Template: Project Kickoff

**Use when:** Contract signed, deposit received, project is starting
**Send:** Immediately after receiving deposit
**Goal:** Confirm project start, set expectations, gather any remaining needs

---

## Subject Line

- [PROJECT NAME] - we're off!
- Kickoff: [PROJECT NAME]
- Let's get started on [PROJECT NAME]

---

## Template

```
Hi [NAME],

Great news - I've received the signed agreement and deposit. [PROJECT NAME] is officially underway!

**Project Overview:**
- **Start Date:** [DATE]
- **Target Completion:** [DATE]
- **Your Investment:** $[AMOUNT] ($[DEPOSIT] received, $[REMAINING] due on delivery)

**What Happens Next:**

**This Week:**
- I'll set up the development environment
- [Any initial technical setup]
- You'll receive access to [project tracking tool / shared folder if applicable]

**What I Need From You:**
- [ ] [Access credentials, API keys, etc.]
- [ ] [Brand assets, content, etc.]
- [ ] [Any other materials]

Please send these by [DATE] so we can stay on schedule.

**Communication:**
- I'll send weekly progress updates every [DAY]
- For quick questions, email is best
- For urgent issues, [phone/text at NUMBER - if applicable]

**Kickoff Call:**
If we haven't already, let's do a quick kickoff call to make sure we're aligned. Does [DATE/TIME] work?

Excited to get started!

Jesse
```

---

## Variation: If No Kickoff Call Needed

```
Hi [NAME],

Deposit received - we're officially underway on [PROJECT NAME]!

**Quick Recap:**
- Start: [DATE]
- Target Delivery: [DATE]
- First milestone: [MILESTONE] by [DATE]

I have everything I need to get started. You'll hear from me [DAY] with the first progress update.

If anything comes up before then, just reply to this email.

Let's build something great.

Jesse
```

---

## Notes

- Confirm the money is received (important for client peace of mind)
- Set clear expectations for communication cadence
- Request any outstanding materials immediately
- Create momentum - project is really happening now
