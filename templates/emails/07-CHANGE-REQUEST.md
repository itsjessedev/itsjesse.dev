# Email Template: Change Request Response

**Use when:** Client requests changes or additions outside original scope
**Goal:** Acknowledge request, clarify scope impact, get approval before proceeding

---

## Subject Line

- Re: [Their subject] - scope update needed
- [PROJECT NAME] - change request details
- Additional scope for [FEATURE]

---

## Template: Minor Change (No Cost)

```
Hi [NAME],

Got your note about [CHANGE REQUEST].

Good news - this is a small adjustment and falls within the project scope. I'll incorporate it into [PHASE/MILESTONE].

You can expect to see this in the next update on [DATE].

Jesse
```

---

## Template: Change Requires Additional Work

```
Hi [NAME],

Thanks for the feedback on [FEATURE/AREA].

I want to make sure we're on the same page about this change, since it falls outside the original scope.

**What You're Asking For:**
[Clear description of the change]

**What This Involves:**
- [Technical work required]
- [Time estimate]

**Impact:**
- **Additional time:** [X hours/days]
- **Additional cost:** $[AMOUNT]
- **Timeline impact:** [None / Extends delivery by X days]

**Options:**

1. **Add to current project** - +$[AMOUNT], delivery moves to [NEW DATE]
2. **Phase 2 addition** - Handle after initial delivery as a separate mini-project
3. **Skip for now** - Proceed with original scope

Let me know which works best for you. If you want to proceed with option 1, I'll send over a quick change order to sign.

Happy to discuss if you want to talk through it.

Jesse
```

**Approval:**

---

## Notes

- Never start work on changes without written approval
- Be clear about cost and timeline impact upfront
- Offer options when possible
- Keep tone helpful, not defensive
- Document everything
